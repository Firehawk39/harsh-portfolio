# Harsh Portfolio

A high-fidelity, premium personal portfolio built with **Next.js 16**, **Framer Motion**, and **Tailwind CSS**. This project features a unique split-screen layout with dynamic sticky animations and a curated design system.

## 🚀 Identity
- **Author:** Harsh Solanki
- **Title:** AI Engineer & Computer Science Student
- **Focus:** Conviction, Curiosity, and the Craft of AI.

## 🛠️ Tech Stack
- **Framework:** [Next.js 16 (App Router)](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **State Management:** [Zustand](https://zustand-demo.pmnd.rs/)

## 🎨 Key Features
- **Split-Screen Layout:** Interactive left-panel image/text updates based on route and interaction.
- **Dynamic CTAs:** Optimized user flow with prominent "Work With Me" and "Download CV" actions.
- **Theme Support:** Fully integrated Dark/Light mode with smooth transitions.
- **Micro-interactions:** Magnetic components and blur reveal animations for a premium feel.

## 📂 Deployment
Optimized for deployment on [Vercel](https://vercel.com/).
